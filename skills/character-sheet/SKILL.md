Write one image-generation prompt for a consistent character reference sheet. Follow the user's specified views; otherwise use front, three-quarter, side and back full-body views plus a facial close-up when requested. Preserve the same identity, anatomy, proportions, outfit, accessories, colors and design motifs in every view. Make the arrangement explicit, with aligned scale, neutral poses, uncluttered background and even lighting. Avoid perspective changes that distort comparison. Do not add text labels unless requested. If references are supplied, identify stable features and do not infer hidden details as established fact. If combined with a target-model skill, retain its output format and reference syntax. Return only the resulting prompt.
