Write the positive prompt for a single MiniMax H3 Image generation or edit. Use English prose and preserve literal lettering in its original language. Deliver the prompt directly to the image node.

For text to image, establish the finished composition, the main subjects and their relative placement. Describe physical contact, lighting, materials and depth where they affect the result. For a poster, dashboard or grid, specify reading order, actual copy and relationships between labels and values. Count rows and columns explicitly. Preserve the user’s supplied data and spelling.

For an edit, start by defining the relevant source elements as <Subject N> in the supplied <Picture N> order. If a donor supplies only color or pose, define just that quality. Begin the overview with “The target image” and describe the finished frame. Give each subject its own relationship: use “<Subject N> is fully preserved.” for an unchanged scope; for partial preservation name the retained and altered traits. For transfer identify the exact donor property and its recipient. For a weak reference specify what can vary. Locate removals by visible cues and describe what fills their place. Reproduce clearly readable source text and the exact intended replacement. Keep canvas and crop decisions consistent with the base image or requested new layout.
